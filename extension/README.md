# CipherVault 浏览器扩展 (Chrome / Edge / Firefox)

CipherVault 官方浏览器扩展插件（基于 Chrome Manifest V3 标准开发），支持主流 Chromium 内核浏览器（Chrome、Edge、Brave、Arc、360 等）以及 Firefox。

---

## ✨ 核心特性

1. **⚡ 当前网站一键自动填充**：自动读取当前标签页域名（如 `github.com`），列出已匹配的账号，点击 `[⚡ 填充]` 瞬间填入用户名与密码。
2. **🛡️ 网页新账号自动捕获**：在任意网站登录新账号时，页面右上角自动弹出保存提示条，一键存入保险库。
3. **🔑 2FA 动态验证码一键复制**：内置 RFC 6238 TOTP 算法，快速复制 30s 动态码。
4. **🎲 随手生成强密码**：无需打开主应用，随时随地在扩展弹窗中生成自定义长度的强密码。
5. **☁️ 全端互通数据同步**：直接复用 GitHub Gist / WebDAV 同步体系，与 Web 版、手机 PWA 版数据实时双向互通。

---

## 🛠️ 安装使用教程 (10 秒快速加载)

### 步骤 1：打开浏览器扩展管理页
* **Google Chrome**: 在地址栏输入 `chrome://extensions/` 回车。
* **Microsoft Edge**: 在地址栏输入 `edge://extensions/` 回车。

### 步骤 2：开启“开发者模式”
* 在扩展管理页面的右上角（或左侧），打开 **“开发者模式” (Developer mode)** 开关。

### 步骤 3：加载扩展目录
* 点击左上角的 **“加载已解压的扩展程序” (Load unpacked)**。
* 在弹出的文件选择框中，选择当前项目的扩展目录：
  ```text
  D:\code\password-vault\extension
  ```
* 确认后，浏览器工具栏即可看到 **CipherVault 密码管家** 盾牌图标！建议点击图钉📌将其固定在工具栏上。

---

## 🚀 首次配置与使用

1. 点击工具栏的 **CipherVault 图标**；
2. 输入您的**主密码**解锁保险库（若您已有云端备份，请使用相同的主密码）；
3. 点击底部的 **`☁️ 云同步`** 标签，填入您的 GitHub Token 与 Gist ID，点击 **“保存配置并双向同步”**；
4. 恭喜！您现有的全部密码已同步至插件，打开任意已保存的网站即可畅享一键自动填充与新账号捕获！
